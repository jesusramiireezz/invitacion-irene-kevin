# 💍 Invitación de Boda – Irene & Kevin

Invitación de boda digital, diseñada y desarrollada a medida con un estilo elegante, limpio y mobile-first.

## ✨ Características

- Hero animado de bienvenida
- Cuenta atrás hasta el día de la boda
- Ubicación con mapa integrado
- Itinerario del evento
- Preguntas frecuentes (FAQ)
- Información de regalo (IBAN)
- Confirmación de asistencia (RSVP)
- Diseño responsive
- Animaciones suaves con Framer Motion

## 🛠️ Tecnologías

- React
- CSS
- Framer Motion
- Font Awesome
- Netlify (deploy)

## 🚀 Deploy

El proyecto se despliega automáticamente en Netlify al hacer push a la rama principal del repositorio.

```bash
npm install
npm run dev
